## [1.0.1] - 2026-05-27

Hotfix для критичного бага в v1.0.0 - віджети не завантажувалися у скачаному `.exe`.

### Виправлено
- **Збірка релізу більше не використовує `PublishSingleFile=true`.** У single-file-режимі widget DLL-файли (`Shelf.Widgets.*.dll`) запаковувалися всередину `Shelf.exe`, але `WidgetRegistry.Initialize()` шукає їх через `Directory.EnumerateFiles("Shelf.Widgets.*.dll")` як окремі файли поруч з виконуваним. Результат у v1.0.0: реєстр віджетів порожній, меню «+ Додати віджет» не показувало жодного типу. Тепер `.zip` містить теку з `Shelf.exe` + ~200 DLL поруч (стандартна self-contained .NET 8 збірка). Розмір zip майже не змінився (~64 МБ).

### Примітки для користувачів v1.0.0
- Завантажте новий `Shelf-v1.0.1-win-x64.zip`, видаліть стару теку, розпакуйте нову, запустіть `Shelf.exe`. Налаштування та додані віджети збережуться (вони в `%APPDATA%\Shelf\`).

## [1.0.0] - 2026-05-26

Перший публічний реліз. Поличка переходить з закритого проекту в open-source під ліцензією MIT.

### Додано
- **Док-панель Windows** з резервуванням простору через AppBar API (праворуч або ліворуч).
- **Темна і світла теми**, перемикання наживо без перезапуску додатка.
- **Українська та англійська локалізації** інтерфейсу.
- **Прихована панель** з анімованим виїздом по наведенню (auto-hide mode).
- **Закріплення віджетів** у верхній зоні (sticky-top), яка не прокручується.
- **Перетягування віджетів** (drag-and-drop) для зміни порядку.
- **Блокування порядку** віджетів для запобігання випадковому перетягуванню.
- **Збереження стану** у `%APPDATA%\Shelf\settings.json` з міграцією з легасі-шляху `%APPDATA%\Помічник\`.
- **Закріплення на всіх віртуальних столах** Windows (за можливості; fallback на переміщення).
- **Автозапуск** разом із системою (опціонально).
- **Системний трей** з тематично-кольоровим меню.
- **Налаштування** з трьома вкладками: Панель, Віджети, Про програму.
- **Перейменування екземплярів** віджетів (подвійний клік на заголовку).

### Віджети (9 вбудованих)
- **Годинник** - час і дата у різних форматах, табулярні цифри.
- **Замітки** - багаторядковий блокнот з автозбереженням.
- **Список задач (Todo)** - to-do з підтримкою мульти-вставки, виконані опускаються вниз з анімацією.
- **Слайд-шоу фото** - перегляд папки з ефектом Ken Burns, 4 типи переходів, регулювання потемніння.
- **Інтернет-радіо** - стрімінг з вбудованим списком українських станцій + редагування власних, нелінійна шкала гучності.
- **Погода** - поточна + завтрашня з Open-Meteo (без API-ключа), кешування координат, ручне і автоматичне оновлення.
- **Таймер** - зворотний відлік зі звуковим сигналом і миготінням після завершення.
- **Секундомір** - відлік до сотих, лапи.
- **Свята** - календар державних, релігійних, професійних і власних свят на 3 дні (вчора/сьогодні/завтра), імпорт з .txt.

### Архітектура
- 11 проектів у складі рішення: хост `Shelf`, SDK `Shelf.Sdk`, 9 віджетів `Shelf.Widgets.*`.
- Власна WPF-стилізація вікон (`ChromeWindow`), темна `DarkMessageBox` замість Win32 MessageBox.
- Унікальний overlay-скролбар головної панелі, який не зменшує ширину віджетів.
- Static project-reference архітектура віджетів (на відміну від runtime-плагінів), що готує проект до Microsoft Store.
