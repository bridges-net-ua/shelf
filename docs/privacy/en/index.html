Privacy Policy

Last updated: 28 May 2026

ShelfDesk (the "Software") is developed by the Bridges Community. The Software respects your privacy: it does not collect telemetry, analytics, or personal data of any kind.

What ShelfDesk does NOT do

  • Does not send telemetry, usage statistics or crash reports to Bridges Community or third-party servers.
  • Does not use cookies, fingerprinting, advertising or tracking SDKs.
  • Does not transmit your files, settings, usage history, contacts, photos or any other personal data.
  • Does not require registration, an account or sign-in.

What network requests ShelfDesk makes

All network requests are strictly related to widgets you have explicitly added to the panel, and they go directly to third-party services - never to Bridges Community servers.

Weather widget

If the widget is added, the Software sends HTTP requests to the Open-Meteo service:

  • geocoding-api.open-meteo.com/v1/search - geocoding of the city name you entered in the widget settings to coordinates.
  • api.open-meteo.com/v1/forecast - current weather and tomorrow's forecast for the resolved coordinates.

Open-Meteo is a free service that requires no API key. No personal identifiers (your name, IP-tied account, request history) are sent. The coordinates derive from the city name and are not precise location data.

Internet Radio widget

The Software streams audio from the URLs of radio stations that are either in the default seed list (Ukrainian stations) or that you have manually added. All requests go directly to the station servers (HTTP/HTTPS, MP3/AAC streams, .pls/.m3u playlists). Bridges Community does not see or log these requests.

NBA widget

If the widget is added, the Software sends requests to the public ESPN API to fetch NBA game scores and schedules. No personal data is sent.

What is stored locally

All settings and state of ShelfDesk are stored exclusively on your computer in:

%APPDATA%\Shelf\settings.json

(For the Microsoft Store version - in the redirected path %LOCALAPPDATA%\Packages\<PackageFamilyName>\LocalCache\Roaming\Shelf\.)

The file contains your selection of widgets, their order, per-widget settings (e.g. city for weather, list of radio stations, your tasks and notes), theme and language choice. No authentication data, tokens or passwords are stored.

Log files

Two diagnostic files may appear in your %TEMP% folder (typically C:\Users\<your_name>\AppData\Local\Temp\):

  • Shelf.crash.log - reports of unhandled exceptions (for debugging).
  • Shelf.vd.log - log of panel moves between Windows virtual desktops.

These files stay exclusively on your computer - ShelfDesk does not transmit them anywhere automatically. You can delete them at any time.

Not for children

ShelfDesk is not directed at children under the age of 13. Because the Software collects no data at all, no special COPPA policy applies.

Changes to this policy

If this policy changes (for example, a new widget with network requests is added), we will update this document and bump the "Last updated" date at the top of the page. Version history of the document is available in the project's git repository.
